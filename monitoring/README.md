# PSI monitoring

Train reference scores сохраняются в `reference_scores.npy`. Скрипт monitoring.py
отправляет выборку через API и считает PSI распределения PD. Ориентиры: <0.1 —
небольшое изменение; 0.1–0.25 — заметное; >=0.25 — существенное. Это эвристика,
порог нужно согласовать с бизнесом. PSI не заменяет контроль качества на новых метках.
